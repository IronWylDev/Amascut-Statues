# Amascut Statues

Shows labels above the four statues/altars during the Amascut fight so you can tell which ones are green or gold at a glance. It also labels inactive, cleansed and empowered altars, with settings to show/hide labels other than gold and green.

This is still a WIP - multiple debug features are currently enabled (logging, state capture) that will be removed once validated, including overlay buttons
